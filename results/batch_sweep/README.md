# 训练集常驻时的双 H100 批大小实验

在同机两张 H100 80GB HBM3 上，每卡 batch 为 2,048 时，这轮 10,000 张图的端到端耗时中位数最低，为 56.3 毫秒。每卡 batch 为 4,096 时，两卡同时有 KNN 核函数的时间占比最高，为 78.0%。设为 5,000 后，每张卡一次处理完整分片，耗时和重叠占比均未取得本轮最佳值。

| 每卡 batch | 每卡分几批 | 耗时中位数（毫秒） | 耗时第 25–75 百分位（毫秒） | 两卡同时计算 | 每秒测试图 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 256 | 20 | 66.2 | 56.7–71.7 | 70.3% | 151,070 |
| 512 | 10 | 62.4 | 51.8–67.7 | 73.7% | 160,341 |
| 1,024 | 5 | 61.6 | 52.8–69.5 | 72.0% | 162,348 |
| 2,048 | 3 | 56.3 | 50.2–59.3 | 70.9% | 177,628 |
| 4,096 | 2 | 59.1 | 57.8–65.4 | 78.0% | 169,322 |
| 5,000 | 1 | 58.1 | 55.8–61.9 | 75.7% | 172,053 |

2,048 比同一轮复测的 256 缩短了 15.0% 的中位耗时，在 18 轮交错对照中有 14 轮更快。2,048 和 5,000 的耗时中位数只差 1.8 毫秒，四分位区间有重叠。4,096 取得最高重叠时，两张卡各自的 KNN 核函数区间覆盖了请求时间的 83.6% 和 87.5%。全部 72 次追踪中，单次最高重叠为 90.9%，出现在 2,048 档。

## 实验条件与指标

- 数据为 MNIST 全部 60,000 张训练图和 10,000 张测试图。每个请求都精确计算 6 亿个平方欧氏距离，保留 FP64、5 近邻和原来的平票规则。两张卡各处理 5,000 张。上限 5,000 覆盖了完整分片。
- 每卡预装 376.8 MB 的训练图和标签。计时从主机查询就绪到主机拿到全部预测，包含查询上传、训练向量范数重算、距离、近邻选择、投票及结果回传。逐卡追踪核实了每次只上传 31.36 MB 的查询并回传 40,000 字节结果。预装、数据读取、核对标签均在计时之外。
- 普通计时和 Nsight Systems 追踪在两个独立进程中进行。每个进程先让每档预热两次，再以轮换顺序交错执行六档。每档有 18 次常规计时、12 次单独追踪。六档在每个执行位置出现的次数相同。180 次请求的输出均与已有 CPU 参考结果逐张相同，正确数均为 9,688。
- 每个请求先分别合并各卡上本进程核函数的重叠区间，再取两卡区间的交集。表中的百分比为同一档 12 次请求的交集时长之和除以相应的端到端追踪时长之和。数据拷贝区间不计入分子。主线程 CUDA 标记与同次 Python 计时的最大差约为 0.0271 毫秒。
- 普通计时前保存的首个整卡忙碌率样本为 82% 和 95%。计时及追踪期间，两张卡上均另有一个计算进程。时间线描述本进程的核函数起止区间，共享调度会影响测量。流式多处理器（SM）和显存带宽的峰值利用率仍待独立测量。

## 文件

- [汇总数据](summary.csv) 含每档耗时、四分位数、吞吐量、核函数重叠、逐卡覆盖率和显存分配峰值。

- `timed/` 和 `traced/` 内的 `boards.csv`、`metadata.json` 分别记录整卡采样和软件环境、源文件哈希、预热与测量参数。`sweep.nsys-rep` 和 `sweep.sqlite` 保留原始进程追踪及其导出。

另一次同机复测把普通计时与追踪都设为每档 5 次。2048 的平均耗时为 34.45 ms，五轮均快于 256。此次复测中平均耗时最低的是 5000（33.94 ms）。两轮的共享负载有变化，原始扫描和复测分别存放。[五次复测汇总](../batch_repeat5/summary.csv)

## 在服务器上复现

在项目根目录 `<project>` 中给新一轮结果指定新的输出目录。

```bash
out=results/batch_sweep_repeat
python3 -B sweep_batch.py --out "$out/timed" --repeats 18
nsys profile --sample=none --cpuctxsw=none --trace=cuda --output="$out/sweep" \
  python3 -B sweep_batch.py --out "$out/traced" --trace --repeats 12
nsys export --type=sqlite --output="$out/sweep.sqlite" "$out/sweep.nsys-rep"
python3 -B analyze_gpu_trace.py --by-batch "$out/sweep.sqlite" "$out/traced/runs.csv" "$out"
python3 -B summarize_batch.py "$out"
```
